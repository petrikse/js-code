Mini kalkulačka je jednoduchá webová aplikácia vytvorená pomocou HTML, a JavaScriptu. Umožňuje používateľovi vykonávať základné matematické operácie, ako je sčítanie a odčítanie dvoch čísel.

Používateľ zadá dve čísla do vstupných polí a následne klikne na tlačidlo pre výpočet. Výsledok sa zobrazí priamo na stránke bez potreby jej obnovenia.
